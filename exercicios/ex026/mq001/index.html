Estou aprendendo a criar Media Queries

Media Query é uma estrutura da CSS que permite aplicar estilizações especificas para uma página web de acordo com certas condições, fazendo assim com esta página possa se adaptar ao layout de tela em diferentes tamanhos e tipos de mídia.

Nesse exercício criamos dois links para CSS. Cada uma das CSS ficaram com suas respectivas configurações, sendo assim o media="screen" com suas configurações de visualização no navegador, e quando solicitamos o print, ou seja, a impressão da página, ele puxa o media="print"
